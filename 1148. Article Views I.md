# 1148. Article Views I
LeetCode: https://leetcode.com/problems/article-views-i/ · Easy

## Problem
Find every author who has viewed at least one of their own articles, sorted by `id` ascending.

**Views**
| Column | Type | Notes |
|---|---|---|
| article_id | int | |
| author_id | int | |
| viewer_id | int | |
| view_date | date | |

`(article_id, viewer_id, view_date)` is the primary key, so the same viewer can appear on the same article across different dates.

**Example**
```
Views: (1, 3, 5, 2019-08-01), (1, 3, 6, 2019-08-02), (2, 7, 7, 2019-08-01),
       (2, 7, 6, 2019-08-02), (4, 7, 1, 2019-07-22),
       (3, 4, 4, 2019-07-21), (3, 4, 4, 2019-07-21)

Output: id = 4, 7
```
Article 2 was viewed by its own author (7), and article 3 was viewed by its own author (4) on two separate rows.

## Solution
```sql
SELECT DISTINCT author_id AS id
FROM Views
WHERE author_id = viewer_id
ORDER BY id;
```

1. `author_id = viewer_id` isolates rows where the person viewing the article is the person who wrote it: article 2's row and both of article 3's rows match.
2. `DISTINCT` collapses author 4's two matching rows (same article, same viewer, different dates) into a single `id`, since duplicate view records shouldn't count as two separate authors.
3. `ORDER BY id` sorts the remaining ids ascending, giving `4, 7`.

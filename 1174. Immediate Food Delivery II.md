# 1174. Immediate Food Delivery II
LeetCode: https://leetcode.com/problems/immediate-food-delivery-ii/ · Medium

## Problem
For each customer's first order (earliest `order_date`), find what percentage were immediate, meaning `order_date = customer_pref_delivery_date`.

**Delivery**
| Column | Type | Notes |
|---|---|---|
| delivery_id | int | primary key |
| customer_id | int | |
| order_date | date | |
| customer_pref_delivery_date | date | |

**Example**
```
Delivery: (1,1,2019-08-01,2019-08-02), (2,2,2019-08-02,2019-08-02), (3,1,2019-08-11,2019-08-12),
          (4,3,2019-08-24,2019-08-24), (5,3,2019-08-21,2019-08-22), (6,2,2019-08-11,2019-08-12),
          (7,4,2019-08-09,2019-08-09)

Output: immediate_percentage = 50.00
```
First orders are customer 1 on 08-01 (scheduled), 2 on 08-02 (immediate), 3 on 08-21 (scheduled), 4 on 08-09 (immediate): 2 of 4 immediate = 50%.

## Solution
```sql
SELECT ROUND(
           AVG(order_date = customer_pref_delivery_date) * 100,
           2
       ) AS immediate_percentage
FROM Delivery
WHERE (customer_id, order_date) IN (
    SELECT customer_id, MIN(order_date)
    FROM Delivery
    GROUP BY customer_id
);
```

1. The subquery finds each customer's earliest `order_date` with `MIN()`. Matching on the tuple `(customer_id, order_date) IN (...)` keeps only the rows that are a customer's first order, discarding customer 1's second order (08-11) and customer 3's later one (08-24).
2. `order_date = customer_pref_delivery_date` evaluates to `1` or `0` per row in MySQL, so `AVG()` over the first-order rows directly gives the proportion that were immediate: (0+1+0+1)/4 = 0.5.
3. Multiplying by 100 and `ROUND(..., 2)` turns that into a percentage with two decimals: 50.00.

The same result comes from ranking each customer's orders with `ROW_NUMBER() OVER (PARTITION BY customer_id ORDER BY order_date)` and filtering to `rn = 1` before running the same `AVG()` calculation. It's a more general pattern worth reaching for whenever a problem asks for the first, last, or Nth row within each group.

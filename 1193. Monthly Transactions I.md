# 1193. Monthly Transactions I
LeetCode: https://leetcode.com/problems/monthly-transactions-i/ · Medium

## Problem
For each month and country, find the total number of transactions and their total amount, plus the same two numbers restricted to approved transactions.

**Transactions**
| Column | Type | Notes |
|---|---|---|
| id | int | primary key |
| country | varchar | |
| state | enum('approved', 'declined') | |
| amount | int | |
| trans_date | date | |

**Example**
```
Transactions:
US | approved | 1000 | 2018-12-18
US | declined | 2000 | 2018-12-19
US | approved | 2000 | 2019-01-01
DE | approved | 2000 | 2019-01-07

Output:
2018-12 | US | 2 | 1 | 3000 | 1000
2019-01 | US | 1 | 1 | 2000 | 2000
2019-01 | DE | 1 | 1 | 2000 | 2000
```
December 2018 in the US has 2 transactions totaling 3000, but only 1 approved for 1000.

## Solution
```sql
SELECT DATE_FORMAT(trans_date, '%Y-%m') AS month,
       country,
       COUNT(*) AS trans_count,
       SUM(state = 'approved') AS approved_count,
       SUM(amount) AS trans_total_amount,
       SUM(IF(state = 'approved', amount, 0)) AS approved_total_amount
FROM Transactions
GROUP BY DATE_FORMAT(trans_date, '%Y-%m'),
         country;
```

1. `DATE_FORMAT(trans_date, '%Y-%m')` collapses the day-level date down to a year-month string, and grouping by that expression together with `country` gives one row per month-country combination.
2. `SUM(state = 'approved')` relies on MySQL treating a boolean expression as 1 or 0, so summing it effectively counts how many rows in the group are approved. It's equivalent to `COUNT(CASE WHEN state = 'approved' THEN 1 END)`, which is more portable to other databases if that matters.
3. `SUM(IF(state = 'approved', amount, 0))` adds up `amount` only for approved rows and treats declined rows as contributing 0, giving the approved-only total alongside the unconditional `SUM(amount)`.
4. Both conditional sums scan the same grouped rows as `COUNT(*)` and `SUM(amount)`, so all four aggregates come out of a single pass with no extra joins or subqueries needed.

# 1204. Last Person to Fit in the Bus
LeetCode: https://leetcode.com/problems/last-person-to-fit-in-the-bus/ · Medium

## Problem
People board a bus one at a time in the order given by `turn`. Find the name of the last person who can board without the cumulative weight exceeding 1000 kg.

**Queue**
| Column | Type | Notes |
|---|---|---|
| person_id | int | primary key |
| person_name | varchar | |
| weight | int | kilograms |
| turn | int | boarding order, 1 = first |

**Example**
```
Queue: (5, Alice, 250, 1), (4, Bob, 175, 5), (3, Alex, 350, 2), (6, John Cena, 400, 3), (1, Winston, 500, 6), (2, Marie, 200, 4)
Output: person_name = John Cena
```
In boarding order the running weight is Alice 250, Alex 600, John Cena 1000, Marie 1200. Marie pushes the total past 1000, so John Cena is the last one who still fits.

## Solution
```sql
SELECT person_name
FROM (
    SELECT person_name,
           weight,
           turn,
           SUM(weight) OVER (ORDER BY turn) AS total_weight
    FROM Queue
) q
WHERE total_weight <= 1000
ORDER BY turn DESC
LIMIT 1;
```

1. `SUM(weight) OVER (ORDER BY turn)` is a running total: for each row it adds that row's weight to every prior row's weight, in `turn` order, without collapsing rows the way a plain `GROUP BY` `SUM` would.
2. That result has to live in a subquery, because `WHERE` is evaluated before window functions run; you can't filter on `total_weight` in the same `SELECT` that computes it.
3. Rows with `total_weight <= 1000` are everyone who still fits once boarded, cumulative weight included: Alice (250), Alex (600), John Cena (1000).
4. `ORDER BY turn DESC LIMIT 1` picks whoever boards latest among that group, which is John Cena at turn 3.

A correlated-subquery version swaps the window function for a per-row `SELECT SUM(weight) FROM Queue WHERE turn <= outer.turn`, computing the same running total by re-scanning the table for every row instead of once. It's worth knowing if window functions aren't available, but it does more repeated work as the table grows.

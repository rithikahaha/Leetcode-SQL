# 1211. Queries Quality and Percentage
LeetCode: https://leetcode.com/problems/queries-quality-and-percentage/ · Easy

## Problem
For each `query_name`, return the **quality** (average of `rating / position`) and the **poor query percentage** (share of rows with `rating < 3`), both rounded to 2 decimal places, in any order.

**Queries**
| Column | Type | Notes |
|---|---|---|
| query_name | varchar | |
| result | varchar | the search result shown, not used in the calculation |
| position | int | rank the result was shown at |
| rating | int | user rating of that result |

**Example**
```
query_name | position | rating
Dog        | 1        | 5
Dog        | 2        | 5
Dog        | 200      | 1
Cat        | 5        | 2
Cat        | 3        | 3
Cat        | 7        | 4

Output:
query_name | quality | poor_query_percentage
Dog        | 2.50    | 33.33
Cat        | 0.66    | 33.33
```
Dog's quality is `(5/1 + 5/2 + 1/200) / 3 ≈ 2.50`; one of its three ratings (`1`) is below 3, so `33.33%`. Cat's quality is `(2/5 + 3/3 + 4/7) / 3 ≈ 0.66`, and again one of three ratings is poor.

## Solution
```sql
SELECT query_name,
       ROUND(AVG(rating / position), 2) AS quality,
       ROUND(AVG(rating < 3) * 100, 2) AS poor_query_percentage
FROM Queries
GROUP BY query_name;
```

1. `AVG(rating / position)` computes the mean of the per-row ratios directly, no need for a separate `SUM`/`COUNT` division.
2. `rating < 3` is a boolean expression, and MySQL evaluates `TRUE`/`FALSE` as `1`/`0` in a numeric context, so `AVG(rating < 3)` is really "fraction of rows where the condition holds." Multiplying by 100 converts that fraction to a percentage.
3. Both `ROUND(..., 2)` calls satisfy the 2-decimal-place requirement independently, since quality and percentage are unrelated metrics computed in the same `GROUP BY` pass.

If you'd rather not lean on MySQL's boolean-to-integer coercion, swap `rating < 3` for `CASE WHEN rating < 3 THEN 1 ELSE 0 END` inside the `AVG()`. It's more verbose but portable to databases that don't treat boolean expressions as numbers.

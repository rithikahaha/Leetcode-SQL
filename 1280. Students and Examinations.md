# 1280. Students and Examinations
LeetCode: https://leetcode.com/problems/students-and-examinations/ · Easy

## Problem
For every student and every subject, count how many times that student appears in `Examinations` for that subject, including a 0 when they never took it. Order by `student_id`, then `subject_name`.

**Students**
| Column | Type | Notes |
|---|---|---|
| student_id | int | primary key |
| student_name | varchar | |

**Subjects**
| Column | Type | Notes |
|---|---|---|
| subject_name | varchar | primary key |

**Examinations**
| Column | Type | Notes |
|---|---|---|
| student_id | int | one row per exam attended |
| subject_name | varchar | |

**Example**
```
Students: (1, Alice), (2, Bob)
Subjects: Math, Physics
Examinations: (1, Math), (1, Math), (2, Physics)

Output:
1 | Alice | Math    | 2
1 | Alice | Physics | 0
2 | Bob   | Math    | 0
2 | Bob   | Physics | 1
```
Alice took Math twice and never took Physics; Bob only took Physics once. Both students still get a row for every subject.

## Solution
```sql
SELECT s.student_id,
       s.student_name,
       sub.subject_name,
       COUNT(e.subject_name) AS attended_exams
FROM Students s
CROSS JOIN Subjects sub
LEFT JOIN Examinations e
    ON s.student_id = e.student_id
   AND sub.subject_name = e.subject_name
GROUP BY s.student_id,
         s.student_name,
         sub.subject_name
ORDER BY s.student_id,
         sub.subject_name;
```

1. `Students CROSS JOIN Subjects` builds every student-subject pair up front, which is what guarantees Alice-Physics and Bob-Math show up even though neither happened.
2. `LEFT JOIN Examinations` then attaches matching exam rows to each pair, leaving `e.student_id` as `NULL` wherever a student never sat that subject's exam.
3. `COUNT(e.subject_name)`, not `COUNT(*)`, is what makes the zero counts work: `COUNT(*)` would count the joined row itself (which always exists after the cross join) even when the exam columns are `NULL`, while `COUNT(column)` ignores `NULL`s and so only counts actual exam attendances.
4. `GROUP BY` collapses the (possibly multiple) matching `Examinations` rows per pair down to one output row with the correct count.

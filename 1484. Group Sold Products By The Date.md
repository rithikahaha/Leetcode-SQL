# 1484. Group Sold Products By The Date
LeetCode: https://leetcode.com/problems/group-sold-products-by-the-date/ · Easy

## Problem
For each `sell_date`, return the number of distinct products sold (`num_sold`) and a comma-separated, alphabetically sorted list of those product names (`products`). The table can contain duplicate rows for the same date and product.

**Activities**
| Column | Type | Notes |
|---|---|---|
| sell_date | date | |
| product | varchar | can repeat within the same date |

**Example**
```
Activities:
2020-05-30 | Headphone
2020-05-05 | Basketball
2020-05-30 | Basketball
2020-05-30 | T-Shirt
2020-05-30 | Headphone

Output:
2020-05-05 | 1 | Basketball
2020-05-30 | 3 | Basketball,Headphone,T-Shirt
```
Headphone appears twice on 2020-05-30 but only counts once, and the three products are listed alphabetically.

## Solution
```sql
SELECT
    sell_date,
    COUNT(DISTINCT product) AS num_sold,
    GROUP_CONCAT(
        DISTINCT product
        ORDER BY product
        SEPARATOR ','
    ) AS products
FROM Activities
GROUP BY sell_date
ORDER BY sell_date;
```

1. `GROUP BY sell_date` collapses all rows for a date into one output row, which is the level the problem asks for.
2. `COUNT(DISTINCT product)` needs the `DISTINCT` because Headphone shows up twice on 2020-05-30; a plain `COUNT(product)` would report 4 products instead of 3.
3. `GROUP_CONCAT(DISTINCT product ORDER BY product SEPARATOR ',')` does two jobs inside one call: `DISTINCT` drops the duplicate Headphone before concatenating, and `ORDER BY product` sorts the names lexicographically before joining them with commas. Both `DISTINCT`s (the one in `COUNT` and the one in `GROUP_CONCAT`) are doing separate work, one for the count and one for the listed names, so neither can be dropped.
4. The trailing `ORDER BY sell_date` is unrelated to the `ORDER BY` inside `GROUP_CONCAT()`; it just sorts the final rows by date instead of the product names within a row.

# 1667. Fix Names in a Table
LeetCode: https://leetcode.com/problems/fix-names-in-a-table/ · Easy

## Problem
Fix every name so only the first letter is capitalized and the rest are lowercase. Return results ordered by `user_id`.

**Users**
| Column | Type | Notes |
|---|---|---|
| user_id | int | primary key |
| name | varchar | mixed-case |

**Example**
```
Users: (1, aLice), (2, bOB)

Output:
user_id | name
1       | Alice
2       | Bob
```

## Solution
```sql
SELECT
    user_id,
    CONCAT(
        UPPER(LEFT(name, 1)),
        LOWER(SUBSTRING(name, 2))
    ) AS name
FROM Users
ORDER BY user_id;
```

1. The name is split into two pieces and each gets its own case treatment: `LEFT(name, 1)` pulls just the first character and `UPPER()` capitalizes it, while `SUBSTRING(name, 2)` grabs everything from the second character onward and `LOWER()` flattens it.
2. `SUBSTRING`'s start position is 1-based in MySQL, so `SUBSTRING(name, 2)` means "start at the second character," not an offset of two characters in.
3. `CONCAT()` glues the two transformed pieces back together: `'A'` and `'lice'` become `'Alice'`.
4. Applying `LOWER()` to the whole string first wouldn't work on its own, since it would also lowercase the first letter. That's why the first character has to be carved out and handled separately from the rest.
5. This runs as a `SELECT`, not an `UPDATE`. The problem wants the corrected names returned in the result set, not written back to the table.

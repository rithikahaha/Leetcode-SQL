# 1683. Invalid Tweets
LeetCode: https://leetcode.com/problems/invalid-tweets/ · Easy

## Problem
Return the IDs of tweets whose content is longer than 15 characters.

**Tweets**
| Column | Type | Notes |
|---|---|---|
| tweet_id | int | primary key |
| content | varchar | |

**Example**
```
Tweets: (1, "Vote for Biden"), (2, "Let us make America great again!")

Output: tweet_id = 2
```
"Vote for Biden" is 14 characters, within the limit. "Let us make America great again!" is 33 characters, over it.

## Solution
```sql
SELECT tweet_id
FROM Tweets
WHERE LENGTH(content) > 15;
```

`LENGTH()` returns the number of bytes in the string, and `WHERE` keeps only the tweets over 15. Since this problem's content is plain ASCII, `LENGTH()` and character count are the same thing here. If the content could contain multibyte characters (emoji, accented letters, non-Latin scripts), `CHAR_LENGTH()` would be the safer choice, since it counts characters rather than bytes and won't overcount a tweet just because it has a few wide characters in it.

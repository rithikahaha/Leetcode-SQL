# 1729. Find Followers Count
LeetCode: https://leetcode.com/problems/find-followers-count/ · Easy

## Problem
For each user, count how many followers they have. Return the result ordered by `user_id` ascending.

**Followers**
| Column | Type | Notes |
|---|---|---|
| user_id | int | |
| follower_id | int | |

`(user_id, follower_id)` is the primary key, so the same follower can't be counted twice for the same user.

**Example**
```
Followers: (0, 1), (1, 0), (2, 0), (2, 1)
Output: (0, 1), (1, 1), (2, 2)
```
User 2 shows up twice, once per follower, so their count is 2.

## Solution
```sql
SELECT user_id,
       COUNT(follower_id) AS followers_count
FROM Followers
GROUP BY user_id
ORDER BY user_id;
```

1. Each row is one follower relationship, so grouping by `user_id` collects all of a user's followers into one group, and `COUNT()` on that group is their follower count.
2. `COUNT(follower_id)` and `COUNT(*)` give the same answer here since `follower_id` is part of the primary key and never null; `COUNT(DISTINCT follower_id)` would be redundant work for the same reason, since the primary key already rules out duplicate follower rows for the same user.
3. `ORDER BY user_id` is ascending by default, matching what the problem asks for.

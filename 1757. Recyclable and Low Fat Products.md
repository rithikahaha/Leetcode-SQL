# 1757. Recyclable and Low Fat Products
LeetCode: https://leetcode.com/problems/recyclable-and-low-fat-products/ · Easy

## Problem
Return the `product_id` of every product that is both low fat and recyclable.

**Products**
| Column | Type | Notes |
|---|---|---|
| product_id | int | primary key |
| low_fats | enum('Y','N') | |
| recyclable | enum('Y','N') | |

**Example**
```
product_id | low_fats | recyclable
0          | Y        | N
1          | Y        | Y
2          | N        | Y
3          | Y        | Y
4          | N        | N

Output: product_id = 1, 3
```
Products 1 and 3 are the only rows with both flags set to `Y`.

## Solution
```sql
SELECT product_id
FROM Products
WHERE low_fats = 'Y'
  AND recyclable = 'Y';
```

A straightforward `WHERE` with both conditions `AND`ed together; each row is checked independently, no joins or aggregation needed since both flags live on the same row.

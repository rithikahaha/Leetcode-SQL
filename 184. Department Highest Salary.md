# 184. Department Highest Salary
LeetCode: https://leetcode.com/problems/department-highest-salary/ · Medium

## Problem
Find the employee(s) with the highest salary in each department. Return `Department`, `Employee`, `Salary` for every such employee (ties all count).

**Employee**
| Column | Type | Notes |
|---|---|---|
| id | int | primary key |
| name | varchar | |
| salary | int | |
| departmentId | int | foreign key to `Department.id` |

**Department**
| Column | Type | Notes |
|---|---|---|
| id | int | primary key |
| name | varchar | |

**Example**
```
Employee: (1, Joe, 70000, 1), (2, Jim, 90000, 1), (3, Henry, 80000, 2), (4, Sam, 60000, 2), (5, Max, 90000, 1)
Department: (1, IT), (2, Sales)

Output:
Department | Employee | Salary
IT         | Jim      | 90000
Sales      | Henry    | 80000
IT         | Max      | 90000
```
Jim and Max both earn 90000, IT's highest, so both qualify. Henry earns Sales' highest, 80000. Joe and Sam earn less than their department's top, so they're excluded.

## Solution
```sql
SELECT
    d.name AS Department,
    e.name AS Employee,
    e.salary AS Salary
FROM Employee e
JOIN Department d ON e.departmentId = d.id
WHERE e.salary = (
    SELECT MAX(e2.salary)
    FROM Employee e2
    WHERE e2.departmentId = e.departmentId
);
```

1. The subquery is correlated: it re-runs for each row of the outer `e`, scoped to that row's own department. For IT it returns 90000, for Sales it returns 80000.
2. `WHERE e.salary = (...)` keeps only employees whose own salary matches their department's max. Jim and Max both earn 90000 in IT, so both pass; Joe's 70000 doesn't. Henry's 80000 matches Sales' max; Sam's 60000 doesn't.
3. `JOIN Department d` just translates `departmentId` into a readable name for the output.
4. Because the filter is `salary = MAX(...)`, ties (Jim and Max) both pass independently, no extra handling needed for multiple winners.

**Alternative using a window function, the same pattern 185 uses for "top three" instead of "top one":**
```sql
SELECT
    d.name AS Department,
    e.name AS Employee,
    e.salary AS Salary
FROM (
    SELECT e.*,
           DENSE_RANK() OVER (PARTITION BY departmentId ORDER BY salary DESC) AS salary_rank
    FROM Employee e
) e
JOIN Department d ON e.departmentId = d.id
WHERE e.salary_rank = 1;
```
`PARTITION BY departmentId` restarts the ranking within each department, and `salary_rank = 1` picks out everyone tied for that department's top salary. This is 185's exact solution with the cutoff changed from `<= 3` to `= 1`, worth knowing since the `MAX()` version above answers "the single highest" specifically and doesn't generalize to "top N" the way this does.

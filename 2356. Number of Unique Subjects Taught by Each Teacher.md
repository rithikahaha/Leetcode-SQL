# 2356. Number of Unique Subjects Taught by Each Teacher
LeetCode: https://leetcode.com/problems/number-of-unique-subjects-taught-by-each-teacher/ · Easy

## Problem
For each teacher, count the distinct subjects they teach, regardless of how many departments they teach a given subject in.

**Teacher**
| Column | Type | Notes |
|---|---|---|
| teacher_id | int | part of primary key (subject_id, dept_id, teacher_id) |
| subject_id | int | |
| dept_id | int | |

**Example**
```
Teacher: (1,2,3), (1,2,4), (1,3,3), (2,1,1), (2,2,1), (2,3,1), (2,4,1)

Output: (1, 2), (2, 4)
```
Teacher 1 teaches subject 2 in two departments and subject 3 in one, which is only 2 unique subjects; teacher 2 teaches four different subjects once each.

## Solution
```sql
SELECT teacher_id, COUNT(DISTINCT subject_id) AS cnt
FROM Teacher
GROUP BY teacher_id;
```

1. `GROUP BY teacher_id` puts each teacher's rows together.
2. `COUNT(DISTINCT subject_id)` matters over plain `COUNT(subject_id)` because teacher 1's subject 2 shows up twice, once per department; without `DISTINCT` they'd be over-counted as 3 subjects instead of 2.
3. Teacher 2 has four distinct subjects, each in its own department, so `DISTINCT` doesn't change anything there, but applying it never hurts since it only removes true duplicates.

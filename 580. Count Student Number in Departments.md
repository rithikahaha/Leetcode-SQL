# 580. Count Student Number in Departments
LeetCode: https://leetcode.com/problems/count-student-number-in-departments/ · Medium

## Problem
Report each department's name and how many students it has, including departments with no students. Order by student count descending, then by department name ascending.

**Student**
| Column | Type | Notes |
|---|---|---|
| student_id | int | primary key |
| student_name | varchar | |
| gender | varchar | |
| dept_id | int | foreign key to `Department.dept_id` |

**Department**
| Column | Type | Notes |
|---|---|---|
| dept_id | int | primary key |
| dept_name | varchar | |

**Example**
```
Student: (1, Jack, M, 1), (2, Jane, F, 1), (3, Mark, M, 2)
Department: (1, Engineering), (2, Science), (3, Law)

Output:
dept_name   | student_number
Engineering | 2
Science     | 1
Law         | 0
```
Law has no students but still has to appear, with a count of 0.

## Solution
```sql
SELECT d.dept_name, COUNT(s.student_id) AS student_number
FROM Department d
LEFT JOIN Student s ON d.dept_id = s.dept_id
GROUP BY d.dept_id, d.dept_name
ORDER BY student_number DESC, d.dept_name;
```

1. The table you start from decides who survives. Starting from `Department` with a `LEFT JOIN` keeps every department, so Law stays in the result even though no student matches it.
2. Law's joined row has `NULL` in every `Student` column. `COUNT(s.student_id)` skips NULLs, so Law gets 0. `COUNT(*)` would count that row and wrongly give Law a 1.
3. `ORDER BY student_number DESC, d.dept_name` sorts by count first, and the department name only breaks ties.

# 584. Find Customer Referee
LeetCode: https://leetcode.com/problems/find-customer-referee/ · Easy

## Problem
Return the names of customers who were not referred by the customer with `id = 2`, including those with no referee at all.

**Customer**
| Column | Type | Notes |
|---|---|---|
| id | int | primary key |
| name | varchar | |
| referee_id | int | nullable, references another customer's id |

**Example**
```
Customer: (1, Will, null), (2, Jane, null), (3, Alex, 2), (4, Bill, null), (5, Zack, 1), (6, Mark, 2)

Output: Will, Jane, Bill, Zack
```
Alex and Mark are excluded because `referee_id = 2`; everyone else has no referee or a different one.

## Solution
```sql
SELECT name
FROM Customer
WHERE referee_id != 2
   OR referee_id IS NULL;
```

1. `referee_id != 2` alone would silently drop every row where `referee_id` is `NULL`, because any comparison against `NULL` evaluates to `UNKNOWN` rather than `TRUE`, and `WHERE` only keeps rows that evaluate to `TRUE`.
2. `OR referee_id IS NULL` explicitly brings those rows back, covering Will, Jane, and Bill.
3. Alex and Mark are still excluded since their `referee_id` is exactly `2`, which fails both conditions.

`WHERE COALESCE(referee_id, 0) != 2` (or MySQL's `IFNULL`) achieves the same thing in a single comparison by substituting a non-2 placeholder for `NULL`, a handy shortcut whenever a `NULL` should be treated as "not the excluded value."

# 595. Big Countries
LeetCode: https://leetcode.com/problems/big-countries/ · Easy

## Problem
A country is "big" if its area is at least 3,000,000 km² or its population is at least 25,000,000. Return the `name`, `population`, and `area` of every big country.

**World**
| Column | Type | Notes |
|---|---|---|
| name | varchar | primary key |
| continent | varchar | |
| area | int | |
| population | int | |
| gdp | bigint | |

**Example**
```
World:
Afghanistan | 652230  | 25500100
Albania     | 28748   | 2831741
Algeria     | 2381741 | 37100000
Andorra     | 468     | 78115
Angola      | 1246700 | 20609294

Output: Afghanistan (25500100, 652230), Algeria (37100000, 2381741)
```
Afghanistan qualifies on population alone (25.5M), and Algeria qualifies on population too even though its area is under 3M. The other three countries miss both thresholds.

## Solution
```sql
SELECT name, population, area
FROM World
WHERE area >= 3000000
   OR population >= 25000000;
```

`OR` returns any row that clears either threshold, which is exactly the definition of "big" here: Afghanistan gets in on population, and a country with a huge area but small population (none in this example, but Canada or Russia in the real table) would get in on area alone.

**Alternative with `UNION`:** run the two conditions as separate `SELECT`s, one filtered by area and one by population, and combine them with `UNION`. `UNION` deduplicates automatically, so a country meeting both conditions still appears once. It's equivalent to the `OR` version here, just split into two scans instead of one.

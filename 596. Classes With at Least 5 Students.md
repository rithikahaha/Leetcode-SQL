# 596. Classes With at Least 5 Students
LeetCode: https://leetcode.com/problems/classes-with-at-least-5-students/ · Easy

## Problem
Return the classes that have 5 or more students enrolled.

**Courses**
| Column | Type | Notes |
|---|---|---|
| student | varchar | |
| class | varchar | |

`(student, class)` is the primary key, so a student can't be enrolled in the same class twice.

**Example**
```
Courses: (A,Math) (B,English) (C,Math) (D,Biology) (E,Math) (F,Computer) (G,Math) (H,Math) (I,Math)

Output: class = Math
```
Math has six students (A, C, E, G, H, I); every other class has only one.

## Solution
```sql
SELECT class
FROM Courses
GROUP BY class
HAVING COUNT(student) >= 5;
```

1. `GROUP BY class` collects all students under their shared class so they can be counted together.
2. `COUNT(student)` counts non-NULL values in that column per group. Since `(student, class)` is the primary key, every row is already a distinct enrollment, so this is equivalent to `COUNT(DISTINCT student)` here without the extra dedup cost. `COUNT(*)` would also work since `student` is never NULL.
3. `HAVING`, not `WHERE`, filters on the aggregate, because `COUNT(student)` only exists after the rows have been grouped. `WHERE COUNT(student) >= 5` would fail, since `WHERE` runs before grouping happens.

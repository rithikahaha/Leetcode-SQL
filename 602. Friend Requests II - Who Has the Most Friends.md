# 602. Friend Requests II: Who Has the Most Friends
LeetCode: https://leetcode.com/problems/friend-requests-ii-who-has-the-most-friends/ · Medium

## Problem
Find the person with the most friends and return their `id` and friend count as `num`. The test data guarantees exactly one person has the maximum.

**RequestAccepted**
| Column | Type | Notes |
|---|---|---|
| requester_id | int | person who sent the request |
| accepter_id | int | person who accepted it |
| accept_date | date | |

Primary key is `(requester_id, accepter_id)`, so the same pair never appears twice.

**Example**
```
requester_id | accepter_id
1            | 2
1            | 3
2            | 3
3            | 4

Output: id = 3, num = 3
```
Person 3 shows up in three accepted friendships (with 1, 2, and 4), more than anyone else.

## Solution
```sql
SELECT id, COUNT(*) AS num
FROM (
    SELECT requester_id AS id FROM RequestAccepted
    UNION ALL
    SELECT accepter_id AS id FROM RequestAccepted
) friends
GROUP BY id
ORDER BY num DESC
LIMIT 1;
```

Tracing the example above:

1. Each accepted friendship involves two people split across two columns, so counting `requester_id` alone would miss anyone who only ever shows up as `accepter_id` (and vice versa). Stacking both columns into a single `id` list fixes that: person 3 ends up appearing three times, once per friendship they're part of.
2. `UNION ALL` matters here, not `UNION`. Plain `UNION` would deduplicate that stacked list down to one row per person, hiding two of person 3's three friendships. The duplicates are the whole point, since each one represents a distinct friendship that needs to be counted.
3. `GROUP BY id` and `COUNT(*)` then just count how many times each id shows up in the stacked list, which is exactly their friend count: person 1 → 2, person 2 → 2, person 3 → 3, person 4 → 1.
4. `ORDER BY num DESC LIMIT 1` returns the top row, person 3 with 3 friends.

**Follow-up: what if more than one person can tie for the max?** `LIMIT 1` would then arbitrarily return just one of them. Swap it for a window function instead:
```sql
SELECT id, num
FROM (
    SELECT id, COUNT(*) AS num, RANK() OVER (ORDER BY COUNT(*) DESC) AS rnk
    FROM (
        SELECT requester_id AS id FROM RequestAccepted
        UNION ALL
        SELECT accepter_id AS id FROM RequestAccepted
    ) friends
    GROUP BY id
) ranked
WHERE rnk = 1;
```
`RANK()` gives every tied top scorer the same rank, so `WHERE rnk = 1` returns all of them instead of an arbitrary one.

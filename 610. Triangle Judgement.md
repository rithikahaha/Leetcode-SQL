# 610. Triangle Judgement
LeetCode: https://leetcode.com/problems/triangle-judgement/ · Easy

## Problem
For each row of three segment lengths, report whether they can form a triangle, labeling every row `'Yes'` or `'No'` rather than filtering any out.

**Triangle**
| Column | Type | Notes |
|---|---|---|
| x | int | |
| y | int | |
| z | int | |

`(x, y, z)` is the primary key.

**Example**
```
Triangle: (13, 15, 30), (10, 20, 15)
Output: (13, 15, 30, No), (10, 20, 15, Yes)
```
13 + 15 = 28, which isn't greater than 30, so the first row fails. The second row passes all three checks.

## Solution
```sql
SELECT x, y, z,
       CASE
           WHEN x + y > z AND x + z > y AND y + z > x THEN 'Yes'
           ELSE 'No'
       END AS triangle
FROM Triangle;
```

1. Three sides form a triangle only if the sum of any two exceeds the third, so all three comparisons must hold together. `AND` is required here, not `OR`: one failing comparison should sink the whole row.
2. The comparison has to be strict `>`, not `>=`. Row 1's 13 + 15 = 28 is not greater than 30, so it fails the very first check and short-circuits to `'No'`.
3. Row 2 passes all three: 10+20>15, 10+15>20, 20+15>10.
4. `CASE` builds a result column instead of filtering rows with `WHERE`, because the problem wants both `'Yes'` and `'No'` rows returned, not just the triangles.

**Follow-up:** since there are only two possible outputs here, MySQL's `IF(condition, 'Yes', 'No')` does the same job in one line and reads a bit more concisely than the full `CASE` block, though `CASE` scales better once you need more than two outcomes.

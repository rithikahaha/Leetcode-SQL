# 620. Not Boring Movies
LeetCode: https://leetcode.com/problems/not-boring-movies/ · Easy

## Problem
Return movies with an odd `id` whose description isn't `"boring"`, ordered by `rating` descending.

**Cinema**
| Column | Type | Notes |
|---|---|---|
| id | int | primary key |
| movie | varchar | |
| description | varchar | |
| rating | float | |

**Example**
```
Cinema: (1, War, great 3D, 8.9), (2, Science, fiction, 8.5),
        (3, irish, boring, 6.2), (4, Ice song, Fantacy, 8.6),
        (5, House card, Interesting, 9.1)

Output: (5, House card, Interesting, 9.1), (1, War, great 3D, 8.9)
```
IDs 2 and 4 are even, so they're out regardless of description. ID 3 is odd but boring, so it's out too. IDs 1 and 5 survive both filters and come back sorted by rating.

## Solution
```sql
SELECT *
FROM Cinema
WHERE id % 2 = 1
  AND description <> 'boring'
ORDER BY rating DESC;
```

1. `id % 2 = 1` keeps only odd IDs: 1, 3, and 5 pass this filter out of the five rows.
2. `description <> 'boring'` then drops id 3 (`irish`, boring), leaving ids 1 and 5.
3. `ORDER BY rating DESC` puts the higher rating first, so id 5 (9.1) comes before id 1 (8.9).
